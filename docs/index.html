Expo native module

User-visible alarms for React Native apps.

Schedule Android alarm-clock alarms and iOS AlarmKit alarms from a small TypeScript API, with native handoff helpers for alarm action routing and completion-gated flows.

Get started Read API docs npm package 
npx expo install react-native-alarm-scheduler
Android Exact alarms + full-screen ring
iOS 26+ AlarmKit scheduling
Expo Config plugin included
Scheduling

App-owned native alarms

Create, list, and cancel alarms with platform-specific native behavior where public APIs support it.

Actions

Native handoffs

Record native alarm actions on both platforms so JavaScript can reconcile app-launch routing after the app foregrounds, even from a cold start.

Sounds

Custom alarm audio

Bundle files for AlarmKit with ios.soundName, or point Android at a raw resource or content URI with android.soundName and android.soundUri.

Usage

Schedule an alarm

The same entry point works across platforms. Android accepts any string id. iOS AlarmKit requires UUID strings when you provide an id. 

import ExpoAlarm from 'react-native-alarm-scheduler';

const permissions = await ExpoAlarm.requestPermissionsAsync();

if (permissions.canScheduleExactAlarms) {
  const alarm = await ExpoAlarm.scheduleAlarmAsync({
    id: '00000000-0000-4000-8000-000000000001',
    hour: 7,
    minute: 30,
    title: 'Morning alarm',
    weekdays: [1, 2, 3, 4, 5],
    ios: {
      alertTitle: 'Morning alarm',
      stopIntentBehavior: 'rescheduleImmediate',
      secondaryButtonTitle: 'Open',
      secondaryButtonBehavior: 'openApp',
      metadata: {
        route: 'alarm-detail'
      }
    },
    android: {
      launchUri: 'myapp://alarm-detail'
    }
  });
}

iOS AlarmKit

AlarmKit handoff and backup helpers

On iOS 26+, the module can record AlarmKit App Intent handoffs before JavaScript listeners are active. Use the async getters after launch or resume to reconcile state.

Durable handoff

getPendingNativeAlarmHandoffAsync() returns the latest stop or secondary action written by the native intent. 

const handoff =
  await ExpoAlarm.getPendingNativeAlarmHandoffAsync();

if (handoff?.action === 'nativeStop') {
  await ExpoAlarm.clearPendingNativeAlarmHandoffAsync();
  // Navigate using handoff.alarmId.
}

Backup timers

scheduleNativeAlarmBackupAsync() schedules a deterministic AlarmKit timer for the logical alarm id. 

await ExpoAlarm.scheduleNativeAlarmBackupAsync(
  alarmId,
  0.1
);

await ExpoAlarm.completeNativeAlarmAsync(alarmId);
await ExpoAlarm.cancelAlarmAsync(alarmId);

Custom audio

Add sound files through the config plugin and pass the bundled filename to AlarmKit. 

await ExpoAlarm.scheduleAlarmAsync({
  hour: 7,
  minute: 30,
  ios: {
    soundName: 'bollywood-alarm.mp3'
  }
});

Android

Alarms that keep ringing

A fired Android alarm starts a foreground service that loops the alarm audio and shows a lock-screen ringing surface. Because the package owns that surface outright, there is no system stop button to work around.

Completion gating

With openMissionOnly the only way out is the button that opens your app. The alarm rings until you say so. 

await ExpoAlarm.scheduleAlarmAsync({
  hour: 7,
  minute: 0,
  android: {
    alertActionMode: 'openMissionOnly',
    secondaryButtonTitle: 'Start mission',
    maxRingDurationSeconds: 0
  }
});

// Later, once the user has actually finished:
await ExpoAlarm.completeNativeAlarmAsync(alarmId);

Audibility

Audio loops on the alarm stream, which ignores the ringer and Do Not Disturb. The volume is pinned for the duration and re-raised whenever anything lowers it. 

android: {
  enforceVolume: true,
  restoreVolume: true,
  volume: 1,
  vibrate: true
}

Required grants

Exact alarms are mandatory: without them the ringing service cannot start. Android 14+ also gates full-screen UI separately. 

const p = await ExpoAlarm.getPermissionsAsync();

if (!p.canScheduleExactAlarms) {
  await ExpoAlarm.requestPermissionsAsync();
}

if (p.canUseFullScreenIntent === false) {
  await ExpoAlarm.openFullScreenIntentSettingsAsync();
}

API

Core methods

Use the full API reference for method signatures, return values, examples, platform behavior, and cleanup order.

getPermissionsAsync()Read native alarm capability and authorization state. requestPermissionsAsync()Request or open the native permission surface where possible. scheduleAlarmAsync(alarm)Schedule an app-owned native alarm. cancelAlarmAsync(id)Cancel a scheduled or active app-owned alarm. getCurrentAlarmContextAsync()Read the active alarm context when available. getPendingAlarmActionsAsync()Read recorded native action history. getPendingNativeAlarmHandoffAsync()Read the latest durable native handoff, on either platform. completeNativeAlarmAsync(id)End a completion-gated alarm and stop the Android ring. getNativeAlarmDebugStateAsync(id)Inspect retry ids, handoff state, and AlarmKit presentation metadata.
