title: Overview

The package exposes the alarm API as its default export and as the named `AlarmScheduler` export:

```ts
import AlarmScheduler from 'react-native-alarm-scheduler';

// Equivalent:
import { AlarmScheduler } from 'react-native-alarm-scheduler';
```

All types are also exported as named exports from the same module.
