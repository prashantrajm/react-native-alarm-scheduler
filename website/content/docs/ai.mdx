This package has real behavioral constraints that are easy to get wrong from an API signature alone —
Android's exact-alarm grant gating the ringing service, iOS AlarmKit's undismissable-alarm limits, and
the fact that events are unreliable by design. These resources exist so a coding agent gets those
rules instead of guessing.

```

```

## Agent skill

The package ships a skill covering the non-obvious rules — permission gating, why event listeners are
the wrong place for routing, UUID ids on iOS, Android inheriting the iOS options, and a debugging
table for "the alarm didn't ring".

It is included in the npm tarball, so after installing the package:

```sh
mkdir -p .claude/skills
cp -R node_modules/react-native-alarm-scheduler/skills/react-native-alarm-scheduler .claude/skills/
```

Or read it [on GitHub](https://github.com/prashantrajm/react-native-alarm-scheduler/blob/main/skills/react-native-alarm-scheduler/SKILL.md).

<Callout>
The skill is written for agents that discover skills from a project directory. Any assistant that can
read a markdown file can use it — the content is plain instructions, not a proprietary format.
</Callout>
